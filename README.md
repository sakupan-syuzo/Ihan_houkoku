# 🏁 モータースポーツ技術違反報告書 自動作成システム (Motorsport Technical Infringement Report Generator)

モータースポーツの公式車検（スクルティネアリング）および技術審判業務において、現場（ピットレーン・管制室・技術室・車検場）のスマートフォンやPCから、公式規則に準拠した**A4技術違反報告書（PDF・印刷用フォーマット）を即座に作成・出力できるPWA対応Webアプリケーション**です。

---

## 🏎️ 主な機能

### 1. 全レースカテゴリ規則マスター完全収録
- **SUPER FORMULA (SF)**: SF統一規則（第21条 ピットエリア、第22条 遮蔽物、第23条 タイヤ、第25条 燃料、第26条 安全、第31条 スタート、第34条 中断・再開）
- **SUPER GT (SGT)**: SGTスポーティングレギュレーション（第21条 タイヤ、第26条 一般安全、第27条 ピットエリア、第28条 燃料、第32条 スタート手順）
- **SUPER FORMULA LIGHTS (SFL)**: SFL統一規則（第21条、第25条、第26条、第31条）
- **スーパー耐久 (S耐)**: S耐スポーツ・技術規則（第10条、第16条、第17条、第18条、附則FCY）
- **JAF 国内競技一般**: JAF国内競技規則（第6章 スタート、第10章 役員・事実判定員）

### 2. 2026年公式レースカレンダー自動マッチング
- アプリ起動時やカテゴリ切り替え時に、現在の日時（または指定日）から**直近・開催中の公式ラウンド（例: `2026 AUTOBACS SUPER GT Round 5 SUZUKA GT 300km RACE`）を自動検出し、大会名へ即座に入力**。
- プルダウンから任意のラウンドを一発選択することも可能。

### 3. 公式書式 A4 レイアウト完全再現
- **タイトル＆ヘッダー**: 二重枠線タイトル、大会名、セッション動的連動（フリー走行／予選／決勝／公式練習／ウォームアップ／その他）、ゼッケンNo.、発生日時、発生場所。
- **表形式の違反内容**: 関連条項、項、チェックボックス（☑ / □）、追記下線（人数・作業内容・状況・服装チェック）。
- **フリースペース（その他 / 特記事項）**: 画面から入力した内容が印字され、空欄時は現場での手書き用余白として機能。
- **フッター署名欄（最下部固定）**: エントラント代表署名、担当技術委員署名、技術委員長署名 ＋ 時刻記入欄がA4用紙最下部にピシッと接地配置。

### 4. 2つの出力モード切り替え
- **「該当違反のみ抽出」モード（実務推奨・A4 1枚完結）**: 選択した違反項目＋フリースペース＋署名欄のみを美しくレイアウトし、必ずA4 1枚に収める公式報告書形式。
- **「全項目様式」モード（原本再現）**: 全項目が並んだ定型チェックシート形式で出力（複数ページ対応）。

### 5. PWA オフライン動作 ＆ ローカル自動保存
- 電波の届きにくいサーキット現場でも、`vite-plugin-pwa` により完全オフライン動作。
- 入力内容はブラウザのLocalStorageに常時自動保存されます。

---

## 🛠️ 技術スタック

- **フレームワーク**: React 19 + TypeScript + Vite 8
- **スタイリング**: Tailwind CSS v4
- **アイコン**: Lucide React
- **オフライン/PWA**: Vite Plugin PWA (Service Worker)
- **帳票・印刷**: Print CSS (@media print, A4 Portrait 1-page fit)

## 🚀 インストール & 開発手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (同一Wi-Fiのスマホからもアクセス可能)
npm run dev

# プロダクションビルド
npm run build
```

---

## 📱 スマートフォンでの利用

1. PCと同じWi-Fiにスマホを接続し、`http://<PCのIPアドレス>:5173` にアクセス。
2. ブラウザ（Safari / Chrome）のメニューから**「ホーム画面に追加」**を選択すると、ネイティブアプリ同様にアイコン化され、オフラインでも起動できます。
